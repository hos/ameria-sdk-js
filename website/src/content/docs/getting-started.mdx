## Requirements

- Node.js **22.12** or later, current **Bun**, or **Deno** 2+ (`import { AmeriaClient } from "npm:@ameria/vpos-sdk"`). The package is ESM; CommonJS code on Node 22.12+ can load it with `require()`.
- A vPOS merchant account with Ameriabank. The bank issues a **client ID**, a **username** and a **password** for the test environment first, and separate ones for production.

## Install

```sh
npm install @ameria/vpos-sdk
```

## Take a payment

<Steps>

1. **Register the payment.** [`initPayment`](/ameria-sdk-js/api/classes/ameriaclient/#initpayment) returns a `url` to the bank's card page.

   <Code code={createPayment} lang="ts" title="create-payment.ts" />

2. **Redirect the payer** to that `url`. They enter their card details on the bank's page — card data never touches your server.

3. **Verify on return.** The bank sends the payer back to your `backUrl`. That redirect is not signed, so ask the bank for the result before fulfilling the order — see [Accept a payment](/ameria-sdk-js/guides/accept-a-payment/).

</Steps>

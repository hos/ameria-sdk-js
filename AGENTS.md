# AGENTS.md

Unofficial TypeScript SDK for the Ameriabank vPOS payment API, published as
`@ameria/vpos-sdk`. ESM-only, Node.js 22.12+, no runtime dependencies.

## Commands

Yarn 4 via Corepack (`corepack enable`).

- `yarn test` — build, then run `node:test` against `dist/`.
- `yarn typecheck` — also type-checks `examples/`.
- `yarn lint` — ESLint, Prettier, publint, attw. Run `yarn format` to fix formatting.
- `yarn docs:dev` / `yarn docs:build` — the Starlight site in `website/`.

Run `yarn lint && yarn typecheck && yarn test` before committing.

## Layout

- `src/client.ts` — `AmeriaClient`, one method per bank endpoint, and its option types.
- `src/types.ts` — response types (the bank's PascalCase field names, typos included:
  `CardBindingFileds`, `IsAvtive` are what the bank sends).
- `src/wire.ts` — request bodies; internal, not exported.
- `examples/` — code shown on the docs site; keep it compiling.
- `website/src/content/docs/` — docs. `api/` is generated by TypeDoc; do not edit it.

## Rules

- Never log or expose credentials; they live in `#private` fields.
- Never add a runtime dependency.
- Public option names are camelCase (`orderId`, `backUrl`); the bank's wire names stay
  PascalCase in request bodies and response types.
- Changing the public API means updating `examples/`, the guides, `CHANGELOG.md` and,
  for breaking changes, `website/src/content/docs/migration.mdx`.
- The bank's reference is `https://servicestest.ameriabank.am/VPOS/help`. Do not guess
  field names or values; say what is unverified.
